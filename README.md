# Partner Integration Adapter

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Fake Partner A/B request transformation, response normalization, retry/circuit-breaker pattern, and DLQ-ready adapter.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
